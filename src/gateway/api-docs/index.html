API Documentation

Welcome to the API documentation. Below are the exposed endpoints for the application.

GET /health

Health check endpoint to verify the service is running. This is used by Hugging Face to check if the space has transitioned from starting to running.

Response

{
  "status": "ok"
}

GET /api/clawhub/search

Searches the ClawHub for available skills. Optionally takes a query parameter ?q=.

Response

{
  "skills": [
    {
      "name": "string",
      "description": "string",
      "author": "string",
      "version": "string"
    }
  ]
}

POST /api/clawhub/install

Installs a skill from ClawHub.

Request Body

{
  "skillName": "string"
}

Response

{
  "message": "string"
}

GET /api-docs

Returns this documentation page.
